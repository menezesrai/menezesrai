A Node.js and Express dashboard originally developed to organize recurring HR tasks, including employee examinations, vacations, and medical certificates. The public repository contains a working preview with fictional data, keeping workplace records private.

A Python application that reads a specific timecard PDF format, extracts relevant entries, and creates Excel workbooks organized by department. It includes both a desktop interface and a command-line option.
